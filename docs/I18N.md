# Translating Knowzone (i18n)

Choosing a language switches **everything the person sees**: every screen's text, plus the AI's explanations.
There are 10 languages: `en`, `pcm` (Nigerian Pidgin), `yo`, `ig`, `ha`, `fr`, `ar` (right-to-left), `sw`, `pt`
and `es`. English is the source; any missing key falls back to English.

## Where things live (`apps/mobile/src/i18n/`)

| File | Purpose |
|---|---|
| `languages.ts` | The language list, RTL flag and date/number locales |
| `index.ts` | i18next setup, `setLanguage`, `formatDate`, `formatTime`, `formatNumber`, `currentLanguage` |
| `provider.tsx` | `LanguageProvider` / `useLanguage()`: one setting, synced to the account and the AI language |
| `errors.ts` | `errorText(e)`: translated message for API errors with a known `reason` |
| `locales/en/<namespace>.ts` | English strings, one file per app area |
| `locales/<lang>/<namespace>.ts` | Translations, same shape (`Translation<typeof en.<ns>>`), keys optional |

## How to translate a screen

```tsx
import { Trans, useTranslation } from 'react-i18next';

const { t } = useTranslation('auth');           // the area's namespace
t('login.title')                                 // auth:login.title
t('actions.continue', { ns: 'common' })          // shared words live in common
t('streak', { count: n })                        // plurals: keys streak_one / streak_other
t('greeting', { name: user.name })               // interpolation: 'Hi {{name}}'
```

Rules:
1. **Every visible string goes through `t()`**: titles, buttons, labels, placeholders, hints, errors, empty
   states, toasts, alerts, and `accessibilityLabel` / `accessibilityHint` (screen readers must speak the
   language too).
2. **Whole sentences, never glued fragments.** Word order differs between languages. Use interpolation
   (`'{{count}} days left'`) or `<Trans>` for styled parts:
   `'Turn any lesson into something you’ll <highlight>actually remember.</highlight>'` with
   `<Trans t={t} i18nKey="welcome.headline" components={{ highlight: <Text … /> }} />`.
3. **Plurals use i18next suffixes** (`_one`, `_other`; Arabic also uses `_zero`, `_two`, `_few`, `_many`) and
   must be called with `count`.
4. **Constants with labels in `lib/`** must not call `t()` at import time; the language can change at runtime.
   Keep ids in the constant and translate where it's rendered (`t(\`exams.${id}\`)`), or turn the constant into
   a function that takes `t`. Keep data the app stores or sends to the server (ids, subject names saved in a
   profile) **unchanged**: translate only for display, e.g. `t(\`subjects.${name}\`, { defaultValue: name })`.
5. **Dates and numbers**: use `formatDate`, `formatTime` and `formatNumber` from `@/i18n`, never
   `toLocaleDateString(undefined, …)` or a hard-coded `'en-GB'`.
6. **Errors**: show `errorText(e)` from `@/i18n/errors` instead of `e.message`, so known reasons are
   translated.
7. **Don't translate**: brand names (Knowzone, Knowzone World, Plus, Pro), exam names (WAEC, JAMB, IELTS…),
   currency symbols, emoji, ids, routes, analytics/event names, console messages, code comments, and learning
   content (lessons, courses, World questions, demo videos). That comes from the backend in the chosen language.
8. **Keys**: camelCase, grouped by screen (`login.title`, `login.forgot`), short and descriptive. Reuse
   `common` for generic words (Continue, Cancel, Save, Back…).
9. **Right-to-left**: avoid `left`/`right` for layout. Prefer `start`/`end` (`marginStart`, `paddingEnd`) and
   flex direction, so Arabic mirrors correctly. Directional icons (`chevron-forward`, `chevron-back`,
   `arrow-forward`, `arrow-back`) must mirror: `const flip = useFlipStyle()` from `@/i18n/provider`, then
   `<Ionicons … style={flip} />`.

## Translations

Each language has `locales/<lang>/<namespace>.ts`:

```ts
import type en from '../en/auth';
import type { Translation } from '../../types';

const auth: Translation<typeof en> = { welcome: { getStarted: 'Bẹ̀rẹ̀ — ọ̀fẹ́ ni' } };
export default auth;
```

Keep `{{placeholders}}` and `<tags>` exactly as in English. Write naturally for students; Nigerian Pidgin
should sound like friendly everyday Naijá. Beta languages (Pidgin, Yoruba, Igbo, Hausa, Arabic, Swahili) need
review by native speakers before launch.
